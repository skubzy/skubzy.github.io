FPGA / RTL

UART Traffic Light Controller

A digital-design portfolio project centered on finite-state-machine control, UART-style serial transmission, baud-rate generation, and hardware-debugging discipline.

VHDL SystemVerilog FSM UART Quartus ModelSim

What I built

  • Traffic-light sequencing modeled as explicit RTL state transitions.
  • UART transmitter concept for status output and debugging visibility.
  • Baud-rate generation and timing logic as first-class design concerns.
  • Simulation-focused verification path before hardware deployment.

Engineering focus

This project is meant to show how I reason about digital systems: clear states, predictable timing, modular testable blocks, and practical debugging hooks instead of treating the FPGA as a black box.
