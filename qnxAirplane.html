QNX Airplane Control System

Embedded

Airport control system prototype and white-hat vulnerability exploration on QNX 8.0 running on Raspberry Pi 5.

Project Overview

After mentoring at the Ross Video hackathon, I joined uOttawaHack to tackle both the NAV CANADA and QNX challenges. The idea was to build an airport control station that communicates with a small plane; when the navigation team detects the aircraft, the system sends a landing clearance. If the pilot does not respond, we switch into an interactive mode using a tilt sensor. A slight tilt toward landing triggers a runway-clearance protocol and rhythmic light flashing.

Beyond the demo, our true goal was to explore vulnerabilities in a QNX 8.0 system: a real flight-critical OS. We aimed to execute a controlled white-hat attack to see how the platform responds to a fault. Time and caution prevented us from carrying out the attack, but the research and setup taught us a great deal about QNX internals and cross-compiling C code to the Raspberry Pi 5.

Achievements

  • Implemented a miniature airport with a plane that tilts downward when approaching, activating runway lights and landing mode.
  • Cross-compiled C programs (including headers) for Raspberry Pi 5 running QNX 8.0.
  • Learned QNX operating system structure and safe vulnerability testing practices.
  • Worked on both navigation communication and control logic under tight deadlines.
